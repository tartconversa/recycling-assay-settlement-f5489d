# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

湿基质量由容器净重给出；水分为质量比例，金属含量按干基质量比例。整批结算干基量为各容器净重乘一减水分之和，不把样本数当权重。assays 的 lt 为低于定量限，此时value为空、limit为已知上界；不是零。sample_id为独立取样，retest_of非空表示同一留样复测，不增加容器代表性。contracts 固定以经双方认可的复检口径计算：干基金属量乘当日价格乘payable_fraction，减干基处理费及合同罚项；超过hard_contaminant_limit不可投入对应线，不能以收益抵消。暂付款在最终应付中抵扣，负差额为待追偿。加工实绩是观测，不给理论化学回收公式；可用范围由历史配料决定，未知配比允许只给情景。

## lots
来料批与合同。

记录键：['lot_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| lot_id | string | 批 |
| supplier_id | string | 供应商 |
| contract_id | string | 合同 |
| received | date | 到货 |
| settlement_due | date | 结算期限 |
| state | string | provisional或disputed |

## containers
容器实物，allocated_kg为已经投入加工湿重。

记录键：['container_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| container_id | string | 容器 |
| lot_id | string | 批 |
| wet_kg | number | 湿重 |
| allocated_kg | number | 已投湿重 |

## allocations
本批次已投入事实；本次加工尚无最终回收实绩，不能从历史加工表冒领。

记录键：['allocation_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| allocation_id | string | 投入 |
| container_id | string | 容器 |
| line_id | string | 线 |
| wet_kg | number | 已投湿重 |
| started_at | datetime | 开始时点 |
| state | string | 已投入状态 |

## samples
独立重取和留样复测区分。

记录键：['sample_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| sample_id | string | 样 |
| container_id | string | 容器 |
| position | string | 取样位置 |
| sampled | date | 取样日 |
| remaining_grams | number | 余样 |
| retest_of | string | 留样原号 |

## assays
原化验读数与定量限。

记录键：['assay_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| assay_id | string | 化验 |
| sample_id | string | 样 |
| lab_id | string | 实验室 |
| analyte | string | 成分 |
| qualifier | string | value或lt |
| value | number | 比例或未知 |
| limit | number | 定量限 |
| available_at | datetime | 可知 |

## references

记录键：['reference_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| reference_id | string | 记录 |
| lab_id | string | 实验室 |
| analyte | string | 成分 |
| assigned | number | 参考值 |
| measured | number | 测值 |
| uncertainty | number | 标准不确定度 |
| available_at | datetime | 可知 |

## contracts
结算和复检口径。

记录键：['contract_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| contract_id | string | 合同 |
| payable_fraction | number | 计价金属比例 |
| processing_fee_kg | number | 干基处理费 |
| contaminant_penalty_kg | number | 超软界部分每千克罚款 |
| soft_contaminant_limit | number | 软界 |
| accepted_basis | string | 认可依据 |
| provisional_fraction | number | 暂付上限比例 |

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| analyte | string | 金属 |

记录键：['line_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |

| --- | --- | --- |

| dry_kg | number | 投入干重 |
| nickel_fraction | number | 干基镍 |
| lithium_fraction | number | 干基锂 |

| recovered_lithium_kg | number | 回收锂 |
