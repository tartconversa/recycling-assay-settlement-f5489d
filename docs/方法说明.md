# 方法说明

本文件说明 `recsettle` 应用的模型、口径与假设；字段含义见 docs/资料口径.md。
所有数字基于合成资料，方法用于演示，不构成真实业务建议。

## 1. 批估值（estimate）

- 干基质量 = Σ 容器净重 × (1 − 水分)，按容器净重加权，不以样本数为权重；
  余料干基同理按（净重 − 已投）计算。
- 化验值先按参考样偏差修正：修正因子 = 参考值 ÷ 测值（每个 实验室×成分 取最新参考记录），
  修正因子的相对标准不确定度 = 参考不确定度 ÷ 测值，该部分不随复测次数摊薄。
- 化验重复性：水分由留样复测对（同一留样两次测量之差）直接估计；
  金属与污染物无复测对，以参考样相对不确定度为代理。
- 取样位置：top 样相对容器平均（以 mixed 样为代表）的偏移用全资料成对差估计，
  偏移量带标准误并计入该抽估的方差。
- 容器间不均匀：由各批内容器抽估值的散布做矩估计（散布 − 平均化验方差），
  再按 within_share（默认 0.5）拆为“真容器间差异 τ²”与“容器内取样误差”。
  每个容器只有一次独立取样，二者不可分别识别，该拆分是假设：
  它只影响“原容器重取 vs 留样复测”的相对收益，不改变批均值。
- 留样复测（retest_of 非空）并入原取样，只摊薄化验重复性方差；
  原容器重取是新的独立抽估，同时压缩容器内取样误差。
- 定量限以下（lt）：按区间 [0, 修正后定量限] 处理。模拟中在区间内抽潜伏值；
  上界口径（censor_mode=upper）按定量限计且不再向批均值收缩。未检出不当成零。
- 联合模拟：批均值 → 容器真值的分层蒙特卡洛（默认 4000 次，固定种子），
  各成分经共同的批均值与偏差因子相关；比例按物理范围截断。
- 贡献分解：一阶分解——分别只保留 水分 / 取样 / 化验 一组来源重算，
  份额 = 该组单独方差 ÷ 各组方差之和；交互作用计入分母不单列。
  干基质量的方差全部来自水分；金属量方差主要由取样（容器间不均匀）贡献。

## 2. 结算（settle）

- 最终应付 = Σ 干基金属量 × 当日价格 × payable_fraction − 干基处理费
  − max(0, 污染物干基比例 − 软界) × 干基量 × 罚单价。
- 已暂付在最终应付中抵扣一次：应付差额 = 最终应付 − 已付；负差额为待追偿，
  已付款不在最终价值之外再支付一次。
- 暂付上限核对：以付款时刻可知证据（available_at ≤ 付款时刻）重估价值中位，
  已付 ≤ 合同暂付比例 × 该中位（容差 2%）。
- 价格：取不晚于估值日的最新价；估值日早于最早价格记录时退回最早一条
  （价格史不在资料内，各截点共用同一参考价，价格风险不另建模）。
- 争议批（disputed）：最终结算须按合同认可依据（mutual_retest）完成双方认可复检；
  结算单只给区间与所需证据，不定案。

## 3. 加工决策（process）

- 回收率没有理论公式，只用历史实绩的经验回归：回收率 ~ [1, 镍, 锂, 污染物]，
  按线分别拟合（最小范数解——合成资料中镍与污染物完全共线，支持范围内预测有效）。
- 配料（镍、锂、污染物）任一维超出该线历史范围即标为“情景”，不作为证据。
- 投入判定：配料污染物中位 > 线硬界 → 不可投入；
  中位 ≤ 硬界 < 97.5% 上界 → 需复检；上界 ≤ 硬界 → 可投入。硬界不用收益抵消。
- 加工成本 = 批固定费 + 单位变动成本 × 湿重（变动成本由历史成本扣除固定费估计）。
- 组合价值 = Σ 加工批净额 − Σ 各批应付差额（结算义务与加工去向无关，每批只计一次），
  因此组合加工、独立处理、全部暂存在同一口径下可比；下行为组合价值的 P5。
- 候选方案：全部暂存、品位优先（朴素基线）、边际优先（污染物感知）、均衡配料。
  计划只用余料（净重 − 已投），已投部分保持原状；同一实物不会同时进入两个加工批。

## 4. 复检规划（plan-recheck）

- 候选动作：有余料的容器可原容器重取（resample）；余样足够的独立取样可留样复测（retained）。
- 预 posterior 分析：假设新证据落在当前后验均值处，比较结算区间（P5–P95）、
  期望罚项、污染物上界与各线投入判定的前后变化。
- 收益为启发式：期望罚项下降 + 结算区间收窄（元），按单位成本收益贪心选择，
  受检验预算、结算期限（动作耗时 ≤ 剩余天数）与余样克数约束。
- 留样复测只压缩化验重复性方差，报告中明示“不能宣称解决容器间不均匀”；
  争议批仅留样复测不满足双方认可依据，需配合重取。

## 5. 审计与检查（audit / check）

- 差额分解：从首笔暂付时刻起，按证据到达时刻逐步重估，
  本批化验、他批化验（经全资料校准参数）与参考样修订分别列示；
  分解路径依赖，已付款与已投料不被重算抹去。
- 可调整性：已加工实物（不可逆转）/ 余料（可改配）/ 结算（可追加或追偿）分列，
  争议、接受、仲裁状态限制可调整范围。
- 一致性检查：质量平衡（台账 vs 投入记录）、在投硬界（已投批按当前证据的污染物上界）、
  暂付上限、计划校验（重复承诺、容量、批次数、硬界、支持范围、争议批承诺）。

## 6. 假设与限制

- within_share = 0.5 是不可识别的拆分假设，改变它会改变重取与复测的相对收益排序
  （重取恒不劣于复测），不改变批均值与结算中位。
- 各成分间不建相关（如水分与品位的相关）；容器内经批均值相关。
- 价格风险、持货成本与副产收益不在资料内，暂存方案只承担结算差额并保留复检期权。
- 历史加工实绩只在已有配料范围内提供证据；超出部分一律标为情景。
